# Blood Work Analyzer

A small Streamlit app that uses a Groq-hosted language model to extract blood test values, flag them against the reference ranges included in a report, and generate a plain-language health summary and practical Indian diet suggestions. A Jupyter notebook with the analysis workflow is also included.

## Project files

- `streamlit_app.py/app.py` — Streamlit user interface and analysis workflow.
- `blood_work_analysis.ipynb` — notebook version of the blood work analysis.
- `blood_work.txt` — sample report you can paste into the app.

## Requirements

- Python 3.14 or newer
- A Groq API key
- Project dependencies installed from the repository's `pyproject.toml`

From the repository root, install dependencies with [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```

Set the API key in an environment variable or in a `.env` file at the repository root:

```dotenv
GROQ_API_KEY=your_groq_api_key
```

Keep API keys private; do not commit `.env` files.

## Run the app

From the repository root:

```bash
uv run streamlit run 2_health_analysis/streamlit_app.py/app.py
```

Paste a blood work report containing test values and reference ranges into the left panel, then select **Analyze**. The right panel displays a health summary and diet suggestions. You can use the included `blood_work.txt` as sample input.

To open the notebook instead:

```bash
uv run jupyter notebook 2_health_analysis/blood_work_analysis.ipynb
```

## Limitations

This is an educational demonstration, not a diagnostic or treatment tool. Results are generated by an AI model and may be incomplete or incorrect. Reference ranges and clinical context matter; discuss laboratory results and any diet or treatment changes with a qualified healthcare professional.
